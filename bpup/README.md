# 聖書箇所ピックアップ (スマホ対応 PWA 版)

文字入力なしで **「書 → 章 → 節」をタップするだけ** で聖書箇所（新改訳2017）を選択し、**選択した瞬間にクリップボードへ自動コピー** するスマホ向け Web アプリ（PWA）です。

## 主な機能
- **文字入力ゼロの3ステップ選択**: 「書名」→「章」→「節」のボタンをタップするだけ（全1章のみの書は自動で章選択をスキップ）。
- **タップと同時に自動コピー**:
  - 1回目の節タップで **その1節を即コピー**（1節だけならそのままメモアプリへ貼り付け可能）。
  - 続けて2回目の節をタップすると **開始節〜終了節の範囲を即座に上書きコピー**。
- **複数箇所のまとめコピー（`＋ 箇所を追加`）**:
  - 異なる書・章の聖句（例：`創世記 1:1-3` と `ヨハネ 3:16`）をキープして、1つのクリップボードにまとめてコピー可能。
- **コピー形式のワンタップ切替**:
  - **各節表記**: 各行に `書名 章:節 本文` を付与
  - **見出し+本文**: 1行目に `書名 章:開始節-終了節`、2行目以降に各節の本文
- **PWA（オフライン＆ホーム画面追加）対応**:
  - スマホのブラウザ（Safari / Chrome）から「ホーム画面に追加」すると、ネイティブアプリのように全画面で起動し、オフラインでも動作します。

## GitHub Pages での公開手順
1. GitHub で新しいリポジトリを作成します。
2. この `pwa` フォルダ内のファイルをすべてリポジトリのルート（直下）にアップロードして Commit / Push します。
3. GitHub リポジトリの **Settings** → **Pages** を開き、**Branch** を `main`（`/ (root)`）に設定して **Save** します。
4. 数十秒〜数分で発行される URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開くと利用できます。
